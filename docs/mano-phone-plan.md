## 2. Ошибки и недоработки на текущем сайте

### 2.1 Критичные (баги и юридические вопросы)
1. **Нет политики конфиденциальности, нет условий, нет cookie-баннера.** `/privatumo-politika/` отдаёт 404. Формы собирают имя и email, а скупка требует паспортные данные, так что это прямое требование GDPR.
2. **Нет реквизитов компании** (UAB / код / PVM код) в футере. Для услуг и продажи в ЛТ они обязательны.
3. **Страница «Kontaktai» сломана:** в блоке «NUMERIS» стоит адрес вместо телефона, заголовок «Musu adresas» без диакритики, на странице нет H1, нет карты и формы.
4. **Тестовая страница в индексе:** `/iphone-remontasgg/` дублирует `/iphone-remontas/`, у неё свой canonical, и она есть в sitemap. Её нужно удалить и поставить 301.
5. **Две разные страницы Facebook** в ссылках (`id=61574463795622` и `id=61574694860896`).
6. **Пункт «Pardavimas» в меню ведёт никуда:** продажи на сайте нет.

### 2.2 Контент и доверие
7. Стаж противоречит сам себе: на главной «8+ metai rinkoje», на Apple-странице «10+ metų patirties», на странице модели «daugiau nei 5 metų».
8. Сроки тоже разные: «30–60 min», «per 20 minučių», «vos per 1 valandą».
9. Телефон записан в разных форматах: `+370 673 06748` и `+370 6 730 6748` (местами с переносом строки посередине номера). Нужен один формат и ссылка `tel:` везде.
10. В прайсах опечатки и пропуски: «Ausiniu lizdo keitimas» без цены, «Dregmes pazeidimu», «Programines irangos», «demių», «vandenių» (правильно «vandeniu»).
11. «Apie mus» звучит как машинный перевод («Mes Specializuojames», «Bet koks ekrano dydis», «Komforto lygis laukiant aptarnavimo»). Нет фото мастеров, салона и реального опыта.
12. Рейтинг «★★★★★ 4.9/5 Google įvertinimas» написан текстом: нет ссылки, нет живых отзывов, нет количества.
13. Нет ни одной реальной фотографии: на главной 2 `<img>`, остальное эмодзи-иконки.
14. Блог мёртв: 3 статьи от апреля 2025.
15. SEO-тексты переспамлены ключами («iPhone remontas paslaugą», «Apple telefonų taisymas pagal pačius aukščiausius standartus», «iPhone 6 ekrano keitimas kaina poreikį»). Google такое пессимизирует.
16. «Pakaitinis telefonas nemokamai» упоминается в тексте, но нигде не вынесено в преимущества.

### 2.3 SEO и техника
17. ~100 одинаковых городских страниц: это thin/doorway content и риск санкций. Лучше 5–10 качественных страниц (Vilnius, Kaunas, Klaipėda, Šiauliai, Panevėžys + «remontas paštu/kurjeriu»).
18. В разметке есть только `Organization` и `WebPage`. Нет `LocalBusiness`/`MobilePhoneRepair` с часами работы, нет `Product`/`Offer`, `FAQPage`, `BreadcrumbList`, хотя FAQ на страницах есть.
19. Нет `hreflang` и других языков. Для Вильнюса русская (и английская) версия заметно расширит аудиторию, а чат уже на русском.
20. Нет lazy-loading, тяжёлый Elementor. Core Web Vitals, скорее всего, слабые, особенно на мобильных.
21. На странице модели прайс-таблица свёрстана не как `<table>`, нет кнопки «Записаться на этот ремонт» прямо у цены.
22. Не видно аналитики (GA4/GTM): непонятно, откуда приходят клиенты и сколько звонков и заявок даёт сайт.
23. Список моделей разбит на страницы «Page 1…5» без поиска и фильтра. Найти свою модель неудобно.
24. Открыты `xmlrpc.php` и REST API `/wp-json/`, видны версии плагинов. Типичная поверхность атак на WordPress.

### 2.4 Конверсия
25. Нет онлайн-записи на ремонт (дата и время).
26. Нет калькулятора «модель → поломка → цена».
27. Нет онлайн-оценки для скупки: «Preliminarus vertinimas internetu» обещан, но на деле это общая форма CF7 «Vardas / El. paštas / Tema».
28. В формах нет поля телефона, хотя клиенты в этой нише в основном звонят и пишут в мессенджеры.
29. Нет кнопок Viber, WhatsApp и Messenger (в коде только упоминание WhatsApp).
30. Нет отслеживания статуса ремонта.

## 3. Новый сайт: архитектура

### 3.1 Стек (рекомендация)
- **Frontend и SSR:** Next.js (App Router) + TypeScript + Tailwind + shadcn/ui. SSR/SSG обязателен для SEO, поэтому SPA на Vite, как в этом репозитории, не подходит для публичной части.
- **База:** PostgreSQL + Prisma.
- **Админка:** своя, в том же Next.js (`/admin`), с ролями (владелец, мастер, продавец).
- **Фото:** S3-совместимое хранилище (Cloudflare R2 / Backblaze) + автоматическая конвертация в WebP/AVIF и ресайз.
- **Платежи (ЛТ):** Paysera или Montonio (банковские ссылки SEB/Swedbank/Luminor + карты); опционально лизинг или рассрочка (Inbank / Mokilizingas).
- **Доставка:** Omniva, LP Express, DPD (пакоматы) через API или Montonio Shipping; самовывоз из салона.
- **Уведомления:** email (Resend / Postmark) + SMS (Twilio или локальный провайдер) + Telegram-бот для персонала.
- **Хостинг:** VPS (Hetzner) с Docker или Vercel + Neon/Supabase. CDN: Cloudflare.
- **Языки:** LT (основной), RU, EN. URL вида `/ru/...`, `/en/...` + `hreflang`.

### 3.2 Разделы сайта
```
/                         Главная
/telefonai                Каталог телефонов на продажу (новые / б/у / восстановленные)
/telefonai/[slug]         Карточка конкретного телефона
/remontas                 Ремонт: выбор типа устройства → бренд → модель
/remontas/[brand]/[model] Прайс модели + запись на ремонт
/supirkimas               Скупка + онлайн-оценка (trade-in калькулятор)
/statusas                 Отслеживание статуса ремонта по номеру заказа
/krepselis, /uzsakymas    Корзина и оформление
/kontaktai                Карта, часы, мессенджеры, форма
/apie-mus, /duk, /blogas

/teisine/...              Privatumo politika, Pirkimo taisyklės, Grąžinimas, Garantija, Slapukai

```

## 4. Каталог телефонов на продажу: как он работает

### 4.1 Модель данных
**Model** (справочник): бренд, серия, модель, год, характеристики (экран, процессор, камера), фото-заглушка. Справочник общий для продажи, ремонта и скупки.

**Item** (конкретный экземпляр на складе):
| Поле | Пример |
|---|---|
| SKU / внутренний номер | MP-2026-0142 |
| Модель | iPhone 14 Pro |
| Память | 128 / 256 / 512 GB |
| Цвет | Deep Purple |
| Тип | Naujas / Naudotas / Atnaujintas (refurbished) |
| Класс состояния | A+ (как новый), A, B, C — с понятным описанием и фото примеров |
| Здоровье батареи | 89 % |
| Что заменено | «Baterija pakeista 2026-10 (originali)» |
| Комплект | коробка, кабель, чехол |
| IMEI / серийный номер | хранится только в админке; в карточке показывается «IMEI patikrintas, ne vogtas, iCloud/FRP atrištas» |
| Блокировки | Neverlocked / SIM-free |
| Гарантия | 3 / 6 / 12 мес. |
| Цена, старая цена | 649 €, ~~699 €~~ |
| Налоговый режим | обычный НДС или маржинальная схема (для б/у) |
| Статус | черновик → в продаже → зарезервирован → продан → архив |
| Фото | 4–8 реальных фото именно этого экземпляра |
| Закупка | откуда (скупка №…, поставщик), закупочная цена — только в админке (для отчёта о марже) |

### 4.2 Витрина
- Фильтры: бренд, модель, память, цвет, класс состояния, цена (слайдер), батарея ≥ X %, гарантия, «в салоне сегодня».
- Сортировка: новые, цена ↑↓, популярные.
- Поиск с автодополнением по модели.
- Бейджи: «Naujas», «Kaip naujas», «-10 %», «Paskutinis».
- Сравнение 2–3 телефонов.
- «Сообщить о поступлении» (подписка на модель: email или SMS, когда появится iPhone 15 128 GB).

### 4.3 Карточка телефона
Галерея реальных фото, цена, класс с пояснением, батарея, гарантия, комплект, а дальше:
- кнопки **«Pirkti»** (оплата онлайн + доставка), **«Rezervuoti salone»** (бронь на 24–48 ч без оплаты), **«Klausti Viber/WhatsApp»**;
- блок **Trade-in:** «Atiduokite savo seną telefoną ir sumokėkite mažiau», который ведёт в калькулятор скупки и вычитает сумму из цены;
- рассрочка от X €/мес.;
- рекомендуемые аксессуары (чехол, стекло) и похожие телефоны.

### 4.4 Заказ
1. Корзина → контактные данные (имя, телефон, email) → способ получения: самовывоз / пакомат / курьер.
2. Оплата: Paysera/Montonio, наличные или карта при самовывозе, рассрочка.
3. Как только заказ создан или оплачен, товар автоматически переходит в «rezervuotas» и пропадает из продажи (защита от двойной продажи единственного экземпляра).
4. Письмо и SMS клиенту, уведомление в Telegram персоналу.
5. Статусы: Naujas → Apmokėtas → Paruoštas → Išsiųstas / Atsiimtas → Užbaigtas, плюс Grąžintas.
6. Счёт-фактура в PDF генерируется автоматически.
7. Возврат 14 дней для покупок на расстоянии (закон ЛТ / ЕС) и форма возврата в личном кабинете.

## 5. Ремонт
- **Перенос всех 99 прайсов** из «prietaisai» в базу: Model × RepairType × цена × время × тип детали (originalas / analogas).
- **Калькулятор:** устройство → бренд → модель → поломки (можно выбрать несколько) → итоговая цена и время.
- **Онлайн-запись:** выбор дня и слота по загрузке мастеров, напоминание по SMS за 2 ч.
- **Ремонт по почте:** форма + генерация этикетки Omniva / LP Express или вызов курьера.
- **Тикет ремонта в админке:** приём (фото устройства, описание, пароль или графический ключ по желанию, подпись клиента на планшете), диагностика, согласование цены (клиенту уходит SMS со ссылкой «Patvirtinti»), ремонт, готово, выдача.
- **Страница `/statusas`:** клиент вводит номер и телефон и видит статус.
- Гарантийный талон в PDF с номером и сроком; гарантийные обращения привязаны к исходному ремонту.
- Учёт запчастей (опционально, 2-й этап): списание детали на ремонт, остатки, порог заказа.

## 6. Скупка (supirkimas) и trade-in
- **Онлайн-калькулятор:** модель → память → состояние экрана, корпуса, батареи → работает / не работает → iCloud отвязан? В ответ клиент получает **предварительную цену** (диапазон).
- Формулы задаются в админке: базовая цена модели × коэффициенты состояния. Базу обновляет владелец (вручную или импортом CSV).
- Заявка: фото + контакты, затем выбор «приеду в салон» или «курьер» (для всей Литвы).
- В салоне: проверка, договор купли-продажи с паспортными данными (обязательно по закону, хранить защищённо и с ограниченным сроком по GDPR), выплата наличными или переводом.
- Купленный телефон одной кнопкой превращается в **Item** каталога продажи (черновик), и вся история сохраняется: закуплен за X, вложено в ремонт Y, продан за Z. Это даёт реальную маржу по каждому телефону.

## 8. SEO и миграция с WordPress (важно не потерять позиции)
1. Выгрузить все URL из sitemap (163 страницы + 99 моделей + категории) и Google Search Console.
2. Сохранить те же URL, где возможно (`/iphone-remontas/`, `/prietaisai/iphone-13-pro/`), а остальные перенаправить 301-редиректами по таблице соответствия.
3. 100 городских страниц склеить: ~10 качественных оставить, остальные перенаправить 301 на `/remontas` или ближайший крупный город.
4. Переписать тексты: меньше спама ключами, больше пользы (реальные сроки, фото, отзывы, FAQ).
5. Разметка Schema.org: `MobilePhoneRepair`/`LocalBusiness` (адрес, часы, гео, рейтинг), `Product` + `Offer` (цена, наличие, состояние `UsedCondition`/`RefurbishedCondition`), `FAQPage`, `BreadcrumbList`, `Service` для ремонта.
6. Автоматические sitemap.xml (по языкам), robots.txt, canonical, Open Graph.
7. Core Web Vitals: цель LCP < 2 s на мобильных, изображения через `next/image`, никакого тяжёлого конструктора.
8. Google Business Profile: синхронизировать данные и вывести на сайт живые отзывы через Places API.

## 9. Юридические требования (Литва и ЕС)
- Privatumo politika (GDPR), Slapukų politika + баннер согласия (Consent Mode v2 для GA и Meta Pixel).
- Pirkimo–pardavimo taisyklės (правила интернет-магазина), право отказа в течение 14 дней, форма отказа.
- Garantijos sąlygos: для ремонта (3 мес.) и для проданных телефонов; для б/у законная гарантия может быть сокращена по договорённости, но не исключена.
- Реквизиты: название, код юрлица, PVM, адрес, контакты в футере.
- Ссылка на платформу ODR (EGS) для споров потребителей.
- Скупка: хранение данных продавцов защищённо, с ограниченным сроком и доступом только по ролям.
- *Тексты стоит проверить у местного юриста или бухгалтера, особенно маржинальную схему НДС для б/у телефонов.*
