# 07. Админ-панель (`/admin`)

Интерфейс на LT (переключение на RU). Адаптивный: телефоны можно публиковать прямо с телефона (фото с камеры).

## Этап 1
| Раздел | Что внутри |
|---|---|
| **Suvestinė** (дашборд) | новые заявки по типам, активные брони (истекают сегодня), телефоны в продаже (количество, сумма, «guli > 30 d.»), позиции прайса без цены, последние 404 |
| **Užklausos** (заявки) | единый список `Lead`: фильтры по типу и статусу, карточка (контакты, модель, работы или ответы скупки, фото), кнопки «Skambinti», «Viber», «WhatsApp», смена статуса, заметка, «Sukurti prekę» (из заявки скупки) |
| **Telefonai** (склад) | таблица `InventoryItem` (статус, модель, цена, дни на витрине); карточка: поля, фото (drag-and-drop, порядок, съёмка с камеры, сжатие в браузере), чеклист публикации, кнопки Publikuoti / Nuimti / Parduota / Archyvuoti / Kopijuoti; печать этикетки (QR + SKU + цена) |
| **Kainoraštis** | матрица «модель × работа», массовые операции, CSV, фильтр «be kainos» |
| **Supirkimo kainos** | базовые цены «модель × память», модификаторы |
| **Modeliai** | бренды и модели: память, цвета, алиасы для поиска, фото, «populiarus», SEO-текст страницы ремонта |
| **Turinys** | страницы (блочный редактор: hero, текст, FAQ, CTA, цены, карта, отзывы), FAQ, баннеры главной; поля RU/EN рядом с LT (заполняются на этапе 3) |
| **SEO** | title и description по страницам, редиректы (таблица + счётчик переходов), журнал 404 с кнопкой «Sukurti peradresavimą» |
| **Nustatymai** | компания и реквизиты, часы работы и праздники, контакты, «факты» (стаж, гарантия, сроки), срок брони, адреса уведомлений Telegram и email |
| **Vartotojai** | персонал, роли, 2FA, журнал действий |

## Этап 2
**Užsakymai:** заказы, оплата, доставка (пакомат, трекинг), «Paruošta» / «Išsiųsta» / «Išduota», возврат денег, счета PDF, экспорт для бухгалтерии.

## Этап 4
Kalendorius (записи) · Remontai (канбан, приём на планшете, тикет) · Supirkimas (проверка, договор, выплата) · Klientai (CRM) · Ataskaitos (выручка, маржа, мастера). Подробности в [05](05-repair.md) и [06](06-buyback.md).

## Роли (этапы 1–2)
| Действие | OWNER | MANAGER | STAFF | CONTENT |
|---|:-:|:-:|:-:|:-:|
| Заявки: смотреть, обрабатывать | ✓ | ✓ | ✓ | — |
| Брони: продлить, отменить, «Parduota» | ✓ | ✓ | ✓ | — |
| Телефоны: создать, фото, публикация | ✓ | ✓ | ✓ | — |
| Телефоны: закупочная цена, IMEI, маржа | ✓ | ✓ | — | — |
| Цена продажи | ✓ | ✓ | — | — |
| Прайс ремонта, цены скупки | ✓ | ✓ | — | — |
| Заказы, возврат денег (этап 2) | ✓ | ✓ | без возврата | — |
| Контент, SEO | ✓ | ✓ | — | ✓ |
| Настройки, пользователи | ✓ | — | — | — |

## Удобство
- Поиск Ctrl+K по номеру заявки, SKU, телефону клиента, модели.
- Telegram-бот: новые заявки, брони, истёкшие брони, ежедневная сводка в 9:00. В сообщении есть кнопка «Atidaryti», она открывает карточку в админке.
- Опасные действия (удаление, массовое изменение цен, возврат денег) идут через подтверждение и пишутся в журнал.
