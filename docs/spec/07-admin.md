# 07. Админ-панель (`/admin`)

Интерфейс на LT (переключение на RU для персонала). Адаптивный: приём и скупка работают на планшете.

## 1. Экраны
| Раздел | Что внутри |
|---|---|
| **Suvestinė** (дашборд) | сегодня: записи, тикеты по статусам, просроченные, заказы к отправке, брони, заявки на скупку · выручка и маржа за день, неделю, месяц · телефоны в продаже: количество, сумма, «guli > 30 d.» · последние отзывы |
| **Kalendorius** | записи на день или неделю, drag-and-drop, создание записи по звонку |
| **Remontai** | канбан и таблица тикетов, фильтры (статус, мастер, канал, просрочка), карточка тикета, экран приёма (05 §5) |
| **Užsakymai** | заказы: таблица, карточка (линии, оплата, доставка, история), действия: «Paruošta», «Sukurti siuntą» (этикетка), «Išduota», «Grąžinimas» |
| **Prekės** (склад) | таблица InventoryItem: фильтры по статусу, модели, источнику и сроку на складе · карточка: поля, фото (drag-and-drop, порядок, обрезка), чеклист проверки, история цены, маржа · действия: Publikuoti / Nuimti / Archyvuoti / Kopijuoti / Spausdinti etiketę (QR + SKU + цена) |
| **Supirkimas** | заявки (канбан), экран проверки и договора, таблица базовых цен, модификаторы |
| **Kainoraštis** | матрица «модель × работа» с инлайн-редактированием, массовые операции, импорт и экспорт CSV, список пустых цен |
| **Modeliai** | справочник брендов и моделей: память, цвета, алиасы, фото, SEO-текст ремонта |
| **Klientai** | поиск по телефону, имени или email · карточка: заказы, ремонты, скупки, согласия, заметки · экспорт и удаление по GDPR («Pamiršti klientą» — анонимизация) |
| **Turinys** | страницы (блочный редактор: hero, текст, FAQ, CTA, цены, карта, отзывы), блог, FAQ, баннеры главной, переводы RU/EN рядом с LT |
| **SEO** | title/description по каждой странице, редиректы (таблица + счётчик переходов + «404 žurnalas» для новых редиректов), статус sitemap |
| **Nustatymai** | компания (реквизиты), часы работы и праздники, запись (слоты, мастера), доставка (цены, перевозчики), оплата (ключи — только индикатор «prijungta»), шаблоны SMS и email, языки, налоги |
| **Vartotojai** | персонал, роли, 2FA, журнал действий |
| **Ataskaitos** | продажи (выручка, маржа по каждому телефону: закупка + подготовка → продажа), ремонт (05 §9), скупка (средняя маржа, оборачиваемость), экспорт для бухгалтерии |

## 3. Удобство
- Глобальный поиск (Ctrl+K) по номеру заказа, тикета или скупки, телефону, IMEI, SKU.
- Сканер QR и штрихкодов камерой: этикетка товара открывает карточку, IMEI подставляется в поле.
- Telegram-бот для персонала: новые заказы, брони, записи, заявки на скупку, согласованные цены. Кнопка в сообщении открывает карточку в админке.
- Печать: этикетка товара (58 мм), акт приёма, гарантийный талон, договор.
- Все опасные действия (удаление, возврат денег, массовое изменение цен) идут через подтверждение и пишутся в `AuditLog`.
