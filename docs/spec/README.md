# ManoPhone: спецификация нового сайта (Next.js)

Новый сайт mano-phone.lt без WordPress: ремонт, продажа телефонов, скупка/trade-in, админка.
Текущий WP не дорабатываем, только переносим данные и URL.

## Ключевые решения (принято по умолчанию, можно поменять)
| Вопрос | Решение | Почему |
|---|---|---|
| Фреймворк | Next.js (App Router) + TypeScript | SSR/SSG для SEO, одна кодовая база для сайта и админки |
| БД | PostgreSQL + Prisma | реляционные данные (заказы, склад, тикеты), транзакции |
| Админка | своя, в том же приложении (`/admin`) | нет лишнего CMS; всё, что нужно, на одном экране |
| Языки | LT на запуске; RU и EN заложены в модели и роутинге, включаются флагом | запуск быстрее, переводы добавляются без переделок |
| Оплата | Montonio (банковские ссылки + карты + рассрочка) | один провайдер для Балтии; Paysera как альтернатива |
| Доставка | Montonio Shipping (Omniva, LP Express, DPD) + самовывоз | один API на все пакоматы |
| Хостинг | Hetzner VPS (EU) + Docker Compose + Caddy, бэкапы в Cloudflare R2 | дёшево, данные в ЕС, без привязки к вендору |
| Репозиторий | **отдельный** (`mano-phone-web`) | текущий `banyamaker-haven` — проект бань на Vite |
| URL | сохраняем рабочие URL текущего сайта, `trailingSlash: true` | не терять позиции в Google |

## Открытые вопросы к владельцу
1. Юр. лицо (UAB / MB / IV), коды, PVM: плательщик НДС или нет? Для б/у телефонов: маржинальная схема?
2. Montonio или Paysera: есть ли уже договор с кем-то?
3. Продаём только телефоны или ещё планшеты, ноутбуки, часы, аксессуары?
4. Сколько сейчас телефонов на продажу и как часто приходят новые?
5. Сколько мастеров и рабочих мест: от этого зависят слоты онлайн-записи.
6. Нужен ли личный кабинет клиента на запуске или хватит «отслеживания по номеру»?
7. RU и EN: на запуске или позже?
8. Фирменный стиль: оставляем текущий логотип или делаем ребрендинг?
