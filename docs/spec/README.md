# ManoPhone: спецификация нового сайта (Next.js)

Новый сайт mano-phone.lt без WordPress. **Главная задача: показывать цены на ремонт, выставлять телефоны на продажу и собирать заявки.** Внутренний учёт работы сервиса (тикеты, приём, мастера, договоры скупки) переносится на последний этап.
Текущий WP не дорабатываем, только переносим с него данные и URL.

## Этапы
| Этап | Что | Срок* |
|---|---|---|
| **1. Сайт (MVP, замена WP)** | прайсы ремонта + калькулятор, витрина телефонов с бронью и вопросами, калькулятор скупки, заявки, контент, юр. страницы, SEO и редиректы, админка: модели, цены, телефоны, заявки, контент | ~6 недель |
| **2. Онлайн-продажа** | корзина, оплата Montonio, пакоматы, письма, счета, возвраты | ~2 недели |
| **3. Рост** | RU/EN, Google Merchant и Facebook-каталог, блог, отзывы, подписки | по мере надобности |
| **4. Управление сервисом** | онлайн-запись по слотам, тикеты ремонта, приём на планшете, статус для клиента, гарантии, договоры скупки, отчёты | ~4–5 недель |

\* для одного full-stack разработчика + дизайн.

## Ключевые решения
| Вопрос | Решение |
|---|---|
| Хостинг | **Hostinger Business** (уже оплачен): Node.js web app для Next.js, MySQL, cron в hPanel. VPS не нужен |
| Фреймворк | Next.js (App Router) + TypeScript + Tailwind + shadcn/ui |
| БД | MySQL / MariaDB (Hostinger) + Prisma |
| Фоновые задачи | таблица `Job` + cron hPanel раз в минуту, без отдельного воркера |
| Фото | Cloudflare R2 (бесплатно до 10 GB), сжатие в браузере перед загрузкой |
| Почта | SMTP почтового ящика Hostinger (входит в тариф) |
| Уведомления персоналу | Telegram-бот (бесплатно) |
| SMS клиентам | не на этапе 1 (платно); подтверждения по email, остальное — звонок или мессенджер |
| Оплата онлайн | этап 2: Montonio (банковские ссылки, карты, рассрочка) |
| Языки | LT на запуске; RU/EN заложены и включаются флагом (этап 3) |
| Репозиторий | отдельный: `mano-phone-web` |
| URL | рабочие URL текущего сайта сохраняются, `trailingSlash: true` |

**Ежемесячные расходы этапа 1 сверх текущего тарифа: ~0 €** (R2, Telegram, почта Hostinger, Cloudflare Free). На этапе 2 добавляется только комиссия Montonio с платежей.

## Открытые вопросы к владельцу
1. Юр. лицо (UAB / MB / IV), коды, PVM: плательщик НДС или нет? Маржинальная схема для б/у?
2. Продаём только телефоны или ещё планшеты, ноутбуки, часы, аксессуары?
3. Сколько телефонов сейчас в продаже и как часто приходят новые?
4. Бронь в салоне: на сколько часов? Нужна ли предоплата?
5. Скупка: есть ли таблица цен, или считаем по формуле от цены продажи?
6. Нужен ли этап 2 (онлайн-оплата и доставка) сразу после запуска или позже?
7. Логотип и фирменный стиль: оставляем или обновляем?
