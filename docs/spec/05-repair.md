# 05. Ремонт

## 1. Прайс
- Источник: `RepairPrice` (модель × работа × качество детали). При импорте: 99 моделей, 1474 цены, из них **151 без цены**, плюс 5 моделей без прайса вообще (Pixel 8 Pro, Apple Watch SE, iPad Pro 2022/2024, iPhone 16e). Список: `migration/repair-prices-missing.csv`, владельцу нужно его заполнить.
- На сайте позиция без цены показывается как «Kaina sutartinė» с кнопкой «Sužinoti kainą» (заявка). Пустую ячейку не показываем.
- Для одной работы могут быть два варианта качества: «Ekrano keitimas — originalas 320 € / analogas 180 €».
- Массовое изменение цен в админке: фильтр (бренд / серия / работа) → «+5 %» или «округлить до 5 €» → предпросмотр → применить (с записью в `AuditLog`).
- Импорт и экспорт CSV в формате, привычном по Ninja Tables (`Remonto darbas;Kaina`), чтобы владельцу было просто перейти.

## 2. Калькулятор (`/telefonu-remonto-kaina/` и виджет на главной)
1. «Įrenginys»: Telefonas / Planšetė / Kompiuteris / Laikrodis.
2. «Modelis»: поиск с автодополнением + плитки популярных. Если модели нет, «Nėra sąraše? Aprašykite» (свободный текст).
3. «Gedimai»: чекбоксы с иконками (Ekranas, Baterija, Krovimas, Kamera, Vanduo, Neįsijungia, Kita). Пункт «Nežinau» ведёт на бесплатную диагностику.
4. Результат: список работ с ценой и сроком, итог, гарантия; если работ несколько, предлагается скидка (настраивается, например −10 € за вторую работу).
5. CTA: **Registruotis į servisą** (дата и время) · **Siųsti paštu / kurjeriu** · **Skambinti**.

## 3. Онлайн-запись (`/registracija/`)
- Настройки (`Setting.booking`): рабочие часы (I–V 10–19, VI 11–17), длина слота (30 мин), сколько мастеров или параллельных приёмов в слоте, буфер до закрытия, выходные и праздники ЛТ (заранее загружены), минимум за 1 ч до записи.
- Длительность записи = сумма `durationMin` выбранных работ, округлённая до слота.
- Клиент выбирает день в календаре, затем свободное время, оставляет имя и телефон (SMS-код для подтверждения номера) и комментарий.
- После записи: SMS и email с `.ics`, напоминание за 24 ч и за 2 ч, ссылка «Perkelti / Atšaukti».
- В админке: календарь дня или недели, перетаскивание записи, отметка «Atvyko» создаёт тикет со статусом `RECEIVED`, «Neatvyko» ставит `no_show`.

## 4. Ремонт по почте или курьером
- Форма «Siųsti telefoną»: модель, проблема, контакты, способ (Omniva, LP Express, DPD, автобусная посылка, наш курьер по Вильнюсу), обратный адрес или пакомат.
- Тикет `NEW` → `AWAITING_DEVICE`. Клиенту приходит инструкция (как упаковать, что вынуть, адрес) и, если подключено, оплаченная этикетка (Montonio Shipping).
- Получили посылку → `RECEIVED` → дальше как обычно. Обратная отправка: после оплаты по ссылке `/statusas/{token}`.

## 5. Приём в салоне (экран админки на планшете)
1. Найти клиента по телефону или создать нового.
2. Модель (поиск), IMEI (сканер камерой: штрихкод из `*#06#`).
3. Состояние: чекбоксы (экран: целый / трещины / не работает; корпус; включается; Face ID; камеры; вода) + 2–4 фото камерой планшета.
4. Проблема со слов клиента, комплект (чехол, SIM-лоток), код разблокировки (по желанию, шифруется).
5. Предварительная цена из прайса, срок готовности.
6. Подменный телефон: выбрать из списка (вести учёт, у кого какой).
7. Подпись клиента пальцем → PDF «Priėmimo aktas» на email + SMS со ссылкой на статус.

## 6. Работа мастера
- Канбан: Diagnostika → Laukia patvirtinimo → Laukia dalių → Remontuojama → Patikra → Paruošta. Карточки сортируются по `dueAt`, просроченные подсвечены.
- В тикете: строки работ (из прайса или вручную), себестоимость детали, внутренние заметки, публичные заметки (видит клиент), фото.
- **Согласование цены:** если итог отличается от предварительного больше чем на X € (настройка), статус становится `AWAITING_APPROVAL`, клиенту уходит SMS «Remonto kaina 140 €. Patvirtinti: link». Клиент жмёт «Patvirtinti» → `APPROVED` с записью времени и IP. По телефону мастер может подтвердить вручную с пометкой «patvirtinta telefonu».
- **Проверка качества:** чеклист после ремонта (те же пункты, что в §2 каталога) → `READY` → SMS «Jūsų telefonas paruoštas».

## 7. Выдача и гарантия
- Выдача: оплата (наличные / карта / ссылка), чек, PDF «Garantinis talonas» (номер, работы, детали, срок по каждой работе) → `COMPLETED`, `warrantyUntil` = max по строкам. Код разблокировки удаляется.
- Гарантийное обращение: поиск по номеру или телефону → «Garantinis remontas» → новый тикет с `parentTicketId`, цена 0, в отчётах помечается отдельно (статистика возвратов по мастеру и типу детали).

## 8. Уведомления по ремонту
| Статус | SMS | Email |
|---|---|---|
| RECEIVED | ✓ номер + ссылка на статус | ✓ акт PDF |
| AWAITING_APPROVAL | ✓ цена + ссылка | ✓ |
| WAITING_PARTS | ✓ (срок) | — |
| READY | ✓ | ✓ |
| COMPLETED | — | ✓ талон + просьба об отзыве (через 1 день SMS со ссылкой на отзыв Google) |
| Не забрали 7 / 14 / 30 дней | ✓ напоминание | — |

## 9. Отчёты по ремонту
Выручка и маржа (цена − детали) по дням, работам, мастерам · среднее время по статусам · % гарантийных возвратов · топ-моделей · источник заявок (сайт / звонок / запись / почта).
