# 05. Ремонт

**Этап 1:** прайс по моделям, калькулятор, заявки (в том числе «отправлю почтой»).
**Этап 4:** онлайн-запись по слотам, тикеты, приём, работа мастеров, статус для клиента, гарантии, отчёты.

## Этап 1

### 1. Прайс
- Данные: `RepairPrice` (модель × работа × качество детали). При импорте 99 моделей и 1474 цены; **151 позиции без цены** и 5 моделей без прайса (Pixel 8 Pro, Apple Watch SE, iPad Pro 2022/2024, iPhone 16e). Список в `migration/repair-prices-missing.csv`, владельцу нужно его заполнить.
- Позиция без цены показывается как «Kaina sutartinė» с кнопкой «Sužinoti kainą». Пустой ячейки нет.
- У одной работы может быть два варианта: «Ekrano keitimas — originalas 320 € / analogas 180 €».
- Админка: матрица «модель × работа» с редактированием прямо в таблице; массовые операции (фильтр по бренду, серии или работе → «+5 %» / «округлить до 5 €» → предпросмотр → применить, с записью в журнал); импорт и экспорт CSV в формате, похожем на текущий Ninja Tables (`Remonto darbas;Kaina`).
- Изменение цены попадает на сайт в течение минуты (`revalidateTag`).

### 2. Страница модели `/remontas/{model}/`
1. H1 «iPhone 13 Pro remontas», фото, короткий уникальный текст.
2. Таблица (`<table>`): Darbas · Detalė (Originalas / Analogas) · Kaina · Trukmė · Garantija · «Registruotis». Можно отметить несколько работ, итог считается внизу.
3. «Nežinote gedimo? Nemokama diagnostika» → форма.
4. «Gyvenate kitame mieste?»: Omniva / LP Express / автобусная посылка / курьер → форма `MAIL_IN`.
5. «Šį modelį taip pat parduodame» (если есть в наличии), похожие модели, FAQ.

### 3. Калькулятор (`/telefonu-remonto-kaina/` и виджет на главной)
1. Тип устройства → 2. модель (автодополнение + плитки популярных; «Nėra sąraše?» — свободный текст) → 3. поломки (чекбоксы с иконками; «Nežinau» → бесплатная диагностика) → 4. итог: работы, цена, срок, гарантия.
5. CTA: **Palikti užklausą** · **Siųsti paštu / kurjeriu** · **Skambinti** · **Viber**.

### 4. Заявка на ремонт (вместо онлайн-записи)
- Форма: имя, телефон (обязательно), email (необязательно), модель и работы (подставляются из калькулятора или прайса), удобное время визита («Šiandien», «Rytoj», «Kita diena» + время, просто как пожелание), комментарий.
- Создаётся `Lead REPAIR` → сообщение в Telegram персоналу («Nauja užklausa Z-2026-00042: iPhone 13 Pro, ekranas 320 €, +370…, rytoj 15:00») → письмо клиенту (если указан email). Ответ клиенту — звонком или в мессенджере, как сейчас.
- `MAIL_IN`: дополнительно способ отправки и обратный адрес; в ответном письме инструкция (как упаковать, адрес салона, что вынуть).

## Этап 4: управление сервисом (в конце)
| Модуль | Что делает |
|---|---|
| **Онлайн-запись** | слоты по часам работы и числу мастеров, длительность по работам, выбор дня и времени клиентом, подтверждение, напоминания (email, при желании SMS), перенос и отмена, календарь в админке |
| **Тикет ремонта** | номер `R-…`, создание из заявки, записи или прямо в салоне; статусы `RECEIVED → DIAGNOSING → AWAITING_APPROVAL → WAITING_PARTS → IN_REPAIR → QUALITY_CHECK → READY → COMPLETED` |
| **Приём на планшете** | поиск клиента по телефону, модель, IMEI (сканер), состояние (чекбоксы + фото), комплект, код разблокировки (шифруется, удаляется после выдачи), подменный телефон, подпись → PDF «Priėmimo aktas» |
| **Канбан мастера** | очередь по сроку, просроченные подсвечены, работы из прайса, себестоимость детали, внутренние и публичные заметки |
| **Согласование цены** | если итог отличается от предварительного, клиент получает ссылку «Patvirtinti / Atsisakyti» (фиксируются время и IP) или мастер отмечает «patvirtinta telefonu» |
| **Статус для клиента** | `/statusas/` по номеру и телефону или по ссылке: прогресс, лента событий, сумма, гарантия |
| **Выдача и гарантия** | оплата, PDF-талон с гарантией по каждой работе, гарантийное обращение со ссылкой на исходный ремонт |
| **Напоминания** | «готово», «не забрали 7 / 14 / 30 дней», просьба оставить отзыв в Google |
| **Отчёты** | выручка и маржа по работам и мастерам, среднее время, % гарантийных возвратов, источники заявок |
