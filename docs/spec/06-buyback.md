# 06. Скупка и trade-in

## 1. Калькулятор оценки (`/supirkimas/` и модалка trade-in)
Шаги (по одному вопросу на экран, прогресс-бар):
1. Модель (поиск) → память (из `storageOptionsGb`).
2. Ar įsijungia ir veikia? — Taip / Ne
3. Ekranas — Be įbrėžimų / Smulkūs įbrėžimai / Įskilęs / Neveikia
4. Korpusas — Kaip naujas / Nusidėvėjęs / Įskilęs, įlenktas
5. Baterija — ≥ 90 % / 80–89 % / < 80 % / Nežinau
6. Face ID / Touch ID veikia? — Taip / Ne
7. iCloud / Google paskyra atsieta? — Taip / Ne (если «Ne», выводится предупреждение «turėsite atsieti prieš pardavimą»)
8. Dėžutė ir kroviklis — Taip / Ne

**Расчёт:** `BuybackBasePrice(model, storage).maxCents` × Π(1 + percent/100) − Σ minusCents, округление вниз до 5 €. Показывается диапазон −10 %…0 % («nuo 270 iki 300 €») и пометка «galutinė kaina po apžiūros».
Если модели нет в базе или включается флаг `rejects`, показывается «Įvertinsime individualiai» с формой и фото.

**Результат:** «Parduoti už ~300 €» → выбор: Atvyksiu į saloną / Kurjeris (visa Lietuva) / Naudoti kaip trade-in. Затем контакты, фото (необязательно), создаётся `BuybackRequest NEW`, SMS с номером.

## 2. Настройка цен в админке
- Таблица «модель × память → максимальная цена» с массовым редактированием и импортом CSV.
- Модификаторы (`BuybackModifier`) — общие для всех моделей, редактируются как таблица «вопрос → ответ → % / € / отказ».
- Подсказка рядом с ценой скупки: текущая цена продажи такой же модели в каталоге и средняя за 90 дней, чтобы видеть маржу.
- Напоминание раз в месяц: «Atnaujinkite supirkimo kainas» (цены на б/у быстро падают).

## 3. Процесс в салоне
1. Открыть заявку (по номеру или телефону) или создать новую на месте.
2. Проверка по чеклисту (как в 04 §2) и фиксация реальных ответов. Система пересчитывает итог.
3. Финальная цена → клиент соглашается → `ACCEPTED`.
4. **Договор купли-продажи:** ФИО, номер документа, дата рождения или личный код (что требует закон, уточнить у юриста), подпись на планшете → PDF. Данные документа шифруются (`sellerIdEncrypted`), доступ только у ролей OWNER/SALES, каждый просмотр пишется в журнал.
5. Выплата: наличные (запись в кассу) или банковский перевод на IBAN → `PAID`.
6. Автоматически создаётся `InventoryItem` (`DRAFT`, `source = BUYBACK`, `costCents = finalCents`, модель, память, цвет, IMEI), который дальше идёт в подготовку и продажу.

## 4. Удалённо (курьер)
`AWAITING_DEVICE` → получили → `INSPECTING` → если реальное состояние хуже, `OFFER_SENT` с новой ценой по SMS-ссылке («Sutinku» / «Grąžinkite») → `ACCEPTED` → перевод в тот же день → `PAID`. При отказе устройство возвращается бесплатно или за счёт клиента (правило задаёт владелец) → `RETURNED`.
Договор удалённо: подтверждение по ссылке + данные документа через форму (или Smart-ID / eParaksts на 3-м этапе).

## 5. Trade-in
- **В салоне при покупке:** клиент выбирает телефон, проходит оценку старого, финальная цена зачитывается в заказ (`Order.tradeInCents`), договор скупки оформляется так же.
- **Онлайн:** результат калькулятора хранится в сессии, в корзине показывается «preliminari nuolaida». Зачесть можно только при самовывозе (см. 04 §5). При доставке клиенту предлагается оформить скупку курьером отдельно.

## 6. Удаление данных
На всех устройствах, принятых в скупку, перед подготовкой к продаже делается сброс, а на тикете ставится отметка «Duomenys ištrinti» (кто и когда). Клиент получает это в PDF договора.
