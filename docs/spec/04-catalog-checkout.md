# 04. Каталог на продажу и оформление заказа

## 1. Классы состояния (показываются клиенту одинаково везде)
| Класс | Название LT | Описание | Пример |
|---|---|---|---|
| — | Naujas | Новый, в заводской плёнке | |
| A+ | Kaip naujas | Без следов использования | после замены корпуса или почти не использовался |
| A | Puikus | Микроцарапины, незаметны с 30 см | |
| B | Geras | Заметные потёртости на корпусе, экран без царапин | |
| C | Patenkinamas | Царапины или сколы, полностью рабочий | самая низкая цена |

На карточке у класса есть ссылка «Kaip vertiname?» с фото-примерами каждого класса.
Батарея: показывается %; если < 85 %, ставится пометка, а при необходимости батарея меняется до продажи (запись в `replacedParts`).

## 2. Проверка перед публикацией (чеклист в админке)
Без отметки всех пунктов кнопка «Publikuoti» заблокирована:
- [ ] IMEI проверен (не в розыске / blacklist, не в рассрочке у оператора)
- [ ] iCloud / Google FRP отвязан, сброс до заводских
- [ ] Тест: экран (битые пиксели, тач), Face ID / Touch ID, камеры, микрофоны, динамики, зарядка, Wi-Fi / BT / NFC, SIM / eSIM, датчики
- [ ] Батарея: % записан
- [ ] Фото: ≥ 3 (перед, зад, бока); дефекты B/C сняты крупно
- [ ] Класс и цена указаны

## 3. Витрина
**Фильтры:** бренд · модель (с поиском) · память · цвет · состояние (Naujas / Atnaujintas / Naudotas) · класс · цена (слайдер) · батарея ≥ 80/85/90 % · гарантия ≥ 6/12 мес. · «Yra salone».
**Сортировка:** Naujausi · Pigiausi · Brangiausi · Populiariausi (по просмотрам за 7 дней).
**Поиск:** Postgres `pg_trgm` + `unaccent` по `DeviceModel.name + aliases`. Запрос «ip 13 pro» находит iPhone 13 Pro.
**Пагинация:** 24 на страницу, «Rodyti daugiau» + обычные ссылки `?page=2` для ботов.

## 4. Карточка `/telefonai/{slug}/`
- Галерея (свайп, зум) реальных фото экземпляра.
- Заголовок: «Apple iPhone 14 Pro 256 GB Deep Purple».
- Бейджи: класс · 🔋 89 % · Garantija 6 mėn. · «IMEI patikrintas» · «Atrakintas».
- Цена, старая цена, «arba nuo 27 €/mėn.» (рассрочка, если включена).
- Кнопки:
  - **Pirkti** → корзина (1 экземпляр, количество не выбирается);
  - **Rezervuoti salone** → короткая форма (имя, телефон) → Order `RESERVED` на 24 ч (настраивается);
  - **Klausti** → Viber / WhatsApp с готовым текстом «Sveiki, domina MP-000142».
- **Trade-in блок:** «Turite seną telefoną? Įvertinkite ir sumokėkite mažiau» → модалка калькулятора скупки → результат сохраняется в сессии и показывается в корзине как зачёт.
- Таблица: модель, память, цвет, состояние, батарея, что заменено, комплект, гарантия, SKU.
- Блоки ниже: «Kaip vertiname būklę», «Pristatymas ir grąžinimas (14 d.)», похожие телефоны (та же модель или серия ±15 % цены), аксессуары (на 2-м этапе).
- Если товар продан, страница отдаёт 200 с плашкой «Parduota» и похожими телефонами (не 404: ссылки и SEO сохраняются). Через 90 дней после продажи `noindex`.

## 5. Корзина и оформление (одна страница `/uzsakymas/`)
1. **Kontaktai:** имя, телефон (обязательно), email (обязательно для чека), галочка «Sąskaita įmonei» → название, код, PVM код, адрес.
2. **Pristatymas:**
   - Atsiėmimas salone: 0 €, «paruošime per 1 val.»;
   - Paštomatas: Omniva / LP Express / DPD, выбор на карте или в списке (Montonio pickup points API), цена из `Setting.shipping`;
   - Kurjeris: адрес, цена.
3. **Mokėjimas:** Banko nuoroda / Kortelė / Išsimokėtinai (через Montonio) · при самовывозе также «Grynais / kortele salone».
4. **Trade-in** (если есть): «−180 € (preliminari, galutinė po patikros salone)». *Правило:* trade-in с онлайн-оплатой не разрешён, только при самовывозе (финальная оценка в салоне). При доставке trade-in оформляется как отдельная скупка с выплатой на счёт.
5. Согласие с `pirkimo-taisykles` (обязательно), подписка на новости (необязательно).
6. **Итог** → «Apmokėti» / «Rezervuoti».

### Защита от двойной продажи
- При нажатии «Apmokėti» в одной транзакции проверяется `status = LISTED`, ставится `RESERVED`, `reservedUntil = now() + 30 min`, создаётся Order `PENDING_PAYMENT`.
- Задача pg-boss через 30 минут возвращает товар в `LISTED`, если оплаты нет.
- Webhook Montonio `paid` переводит Order в `PAID`, Item в `SOLD`, отправляет письмо и SMS клиенту, уведомляет Telegram персонала и генерирует PDF-счёт.
- Если оплата пришла после снятия резерва и товар уже купил другой клиент, автоматически делается возврат денег и отправляется письмо с извинением (редкий случай, но описан).

## 6. Письма и SMS (шаблоны)
| Событие | Email | SMS |
|---|---|---|

| Оплачен | ✓ + PDF-счёт | ✓ |

## 7. Возвраты (14 дней, покупка на расстоянии)
- В письме и кабинете: «Grąžinti prekę» → форма (причина, способ возврата) → Order `REFUNDED` после проверки → Item `RETURNED` → проверка → `DRAFT`/`LISTED`.
- Возврат денег через Montonio refund API тем же способом оплаты в течение 14 дней (требование ЕС).
- Покупки в салоне: возврат по правилам магазина (не обязателен по закону; решает владелец).

## 8. Счета и налоги
- Номер счёта по серии `MP` + год + номер.
- `MARGIN`: в счёте нет выделенного НДС, пометка «Taikoma maržos apmokestinimo schema» (точная формулировка — у бухгалтера).
- `STANDARD`: НДС 21 % выделяется.
- Экспорт за месяц в CSV/XLSX для бухгалтерии (или интеграция с Rivilė / B1.lt / Centas на 2-м этапе).
- Требования i.SAF и i.EKA уточнить у бухгалтера.
