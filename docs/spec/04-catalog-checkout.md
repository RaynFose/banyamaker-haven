# 04. Телефоны на продажу

**Этап 1:** витрина, карточки, бронь в салоне, вопрос по телефону, подписка на модель.
**Этап 2:** корзина, онлайн-оплата, доставка в пакомат, счета, возвраты.

## 1. Классы состояния (одинаково везде)
| Класс | LT | Описание |
|---|---|---|
| — | Naujas | Новый, в заводской плёнке |
| A+ | Kaip naujas | Без следов использования |
| A | Puikus | Микроцарапины, незаметны с 30 см |
| B | Geras | Заметные потёртости на корпусе, экран без царапин |
| C | Patenkinamas | Царапины или сколы, полностью рабочий |

У класса на карточке есть ссылка «Kaip vertiname?» с фото-примерами. Батарея показывается в %, если ниже 85 % — с пометкой.

## 2. Чеклист перед публикацией (в админке)
Без всех отметок кнопка «Publikuoti» неактивна:
- [ ] IMEI проверен (не в розыске, не в рассрочке)
- [ ] iCloud / Google FRP отвязан, сброс до заводских
- [ ] Протестированы экран, Face/Touch ID, камеры, звук, зарядка, связь
- [ ] Записан % батареи
- [ ] ≥ 3 фото (перед, зад, бока; дефекты B/C — крупно)
- [ ] Указаны класс и цена

## 3. Витрина `/telefonai/` (этап 1)
- **Фильтры:** бренд · модель · память · цвет · состояние (Naujas / Atnaujintas / Naudotas) · класс · цена (слайдер) · батарея ≥ 80/85/90 % · гарантия.
- **Сортировка:** Naujausi · Pigiausi · Brangiausi · Populiariausi (по просмотрам).
- **Поиск** по `searchText`: «ip 13 pro» находит iPhone 13 Pro.
- 24 товара на страницу, «Rodyti daugiau» + обычные ссылки `?page=2`.
- Параметры фильтров сохраняются в URL, но canonical указывает на страницу без параметров. Страницы брендов `/telefonai/apple/` индексируются.
- **Карточка в сетке:** фото, «iPhone 14 Pro · 256 GB · Deep Purple», класс, 🔋 89 %, цена, старая цена, гарантия.
- **Пусто:** «Šiuo metu tokio nėra» + форма «Pranešti, kai atsiras» (`StockAlert`, по email).

## 4. Карточка `/telefonai/{slug}/` (этап 1)
- Галерея реальных фото экземпляра (свайп, зум).
- Заголовок, бейджи: класс · батарея · гарантия · «IMEI patikrintas» · «Atrakintas».
- Цена и старая цена.
- **Кнопки этапа 1:**
  - **Rezervuoti salone** → форма (имя, телефон, email необязательно, «kada atvyksite») → `Lead RESERVATION`, товар `RESERVED` на N часов (настройка, по умолчанию 24 ч) → письмо клиенту (если указан email), сообщение в Telegram персоналу. На карточке вместо кнопки появляется «Rezervuotas iki …».
  - **Skambinti** · **Viber** · **WhatsApp** с готовым текстом «Sveiki, domina MP-000142 (iPhone 14 Pro 256 GB)».
  - **Klausti** → короткая форма → `Lead QUESTION`.
- Блок «Turite seną telefoną? Įvertinkite» → калькулятор скупки (06) с пометкой «trade-in» в заявке.
- Таблица характеристик: модель, память, цвет, состояние, батарея, что заменено, комплект, гарантия, SKU.
- Похожие телефоны (та же модель или серия, ±15 % цены).
- **Продан:** страница остаётся (200) с плашкой «Parduota» и похожими телефонами; через 90 дней получает `noindex`.

## 5. Бронь: правила
- Бронь можно поставить только на `LISTED`. Проверка и смена статуса идут в одной транзакции, поэтому две брони на один телефон невозможны.
- Истёкшая бронь (`reservedUntil < now`) сразу считается свободной; cron приводит статус в порядок и пишет в Telegram «Rezervacija baigėsi: MP-000142».
- В админке: «Pratęsti» (продлить), «Atšaukti» (отменить), «Parduota» (→ `SOLD`, `Lead DONE`).
- Лимит: не больше 2 активных броней на один номер телефона.

## 6. Этап 2: онлайн-покупка
1. **Kontaktai:** имя, телефон, email, «Sąskaita įmonei» (название, код, PVM, адрес).
2. **Pristatymas:** самовывоз (0 €) · пакомат Omniva / LP Express / DPD (выбор из списка Montonio) · курьер.
3. **Mokėjimas** через Montonio: банковская ссылка, карта, Apple/Google Pay, рассрочка.
4. Согласие с `pirkimo-taisykles`.

**Защита от двойной продажи:** при «Apmokėti» в транзакции `LISTED → RESERVED` (30 мин) + `Order PENDING_PAYMENT`. Webhook Montonio `paid` (проверка подписи, идемпотентно по `paymentRef`) → `Order PAID`, товар `SOLD`, письмо с PDF-счётом, сообщение в Telegram. Без оплаты через 30 мин товар возвращается в продажу. Если оплата пришла после того, как телефон купил другой клиент, делается автоматический возврат и отправляется письмо.

**Письма этапа 2:** заказ создан (напоминание через 15 мин без оплаты) · оплачен + счёт · готов к выдаче · отправлен + трекинг · возврат оформлен.

**Возврат 14 дней** (покупка на расстоянии): форма из письма → проверка → refund через Montonio тем же способом → товар `DRAFT` → проверка → снова в продажу.

**Счета:** серия `MP` + год + номер. Для `MARGIN` — без выделенного НДС с пометкой о маржинальной схеме (формулировку даёт бухгалтер), для `STANDARD` — НДС 21 %. Ежемесячный экспорт CSV/XLSX для бухгалтерии.
