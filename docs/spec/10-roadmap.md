# 10. Дорожная карта

Оценка дана для 1 full-stack разработчика (+ дизайн). Спринт = 1 неделя. Хостинг — Hostinger Business.

## Этап 1: сайт вместо WordPress (~6 недель)

### Спринт 0. Подготовка
- [ ] Ответы владельца на вопросы (README), реквизиты, логотип, фото салона.
- [ ] Репозиторий `mano-phone-web`, CI (lint, typecheck, test, build).
- [ ] Hostinger: Node.js app для staging (`staging.mano-phone.lt`, Basic Auth), БД MySQL, cron. Cloudflare: R2, Turnstile. Telegram-бот.
- [ ] Дизайн: UI-kit + макеты (главная, прайс модели, калькулятор, витрина, карточка телефона, скупка; мобильная и десктоп-версии).
- [ ] Выгрузка из Search Console, фиксация текущих позиций.
**Готово, когда:** «hello world» на Next.js задеплоен из GitHub на staging Hostinger и подключён к MySQL, cron вызывает `/api/cron`, макеты утверждены.

### Спринт 1. Фундамент
- [ ] Next.js + Tailwind + shadcn, next-intl (lt; ru/en под флагом), шапка, футер, мобильная панель «Skambinti / Viber / WhatsApp».
- [ ] Prisma (MySQL) по `schema.prisma`; seed: 20 типов работ, 99 моделей, 1474 цены, 273 редиректа.
- [ ] Вход в админку (2FA), роли, каркас админки; `Setting` (компания, часы, контакты, факты).
- [ ] Middleware: редиректы из БД, журнал 404. Очередь `Job` + `/api/cron`.
**Готово, когда:** `/prietaisai/iphone-13-pro/` отдаёт 301 на `/remontas/iphone-13-pro/` с таблицей цен из БД.

### Спринт 2. Ремонт
- [ ] Страницы: прайс модели, бренд-посадочные (`/iphone-remontas/`, `/samsung-remontas/` …), хабы, калькулятор, «Remontas visoje Lietuvoje», шаблон города.
- [ ] Формы заявки `REPAIR` / `MAIL_IN`, Telegram, письмо клиенту.
- [ ] Админка: модели, матрица цен, массовые операции, CSV; раздел «Užklausos».
- [ ] Владелец: заполнить 151 пустую цену и 5 моделей, добавить iPhone 17 и Galaxy S25.
**Готово, когда:** клиент находит модель, видит цену и оставляет заявку, персонал получает её в Telegram; изменённая в админке цена появляется на сайте ≤ 1 мин.

### Спринт 3. Телефоны на продажу
- [ ] Админка «Telefonai»: карточка, фото (сжатие в браузере → R2), чеклист, статусы, этикетка.
- [ ] Витрина: фильтры, сортировка, поиск, пагинация; карточка; «Parduota»; `StockAlert`.
- [ ] Бронь (`Lead RESERVATION`, транзакция, срок, истечение), «Klausti», кнопки мессенджеров.
- [ ] Блок «Naujausi telefonai» на главной.
**Готово, когда:** телефон, опубликованный с телефона сотрудника, через минуту виден на витрине; две одновременные брони одного телефона невозможны (тест); LCP мобильной витрины < 2 с.

### Спринт 4. Скупка + контент
- [ ] Калькулятор скупки, базовые цены и модификаторы в админке, `Lead BUYBACK`, «Sukurti prekę» из заявки.
- [ ] Блочный редактор страниц. Переписать и перенести: главная, «Apie mus», инфо (5), скупка (4), контакты, 11 городов.
- [ ] Юр. страницы: privatumas, slapukai, garantija, (для этапа 2: pirkimo taisyklės, grąžinimas). Cookie-баннер + Consent Mode.
- [ ] Блог: 4 существующие статьи с редиректами.
**Готово, когда:** у всех keep-URL из `redirects.csv` есть новый контент, юр. тексты проверены владельцем.

### Спринт 5. SEO, проверка, запуск
- [ ] JSON-LD (`MobilePhoneRepair`, `Service`, `Product` + `Offer`, `FAQPage`, `BreadcrumbList`), sitemap, robots, OG-картинки.
- [ ] GA4 + GTM (события), Search Console, отзывы Google.
- [ ] Lighthouse ≥ 90 (mobile), проверка доступности, краулер по staging, скрипт проверки всех 273 редиректов.
- [ ] Sentry, UptimeRobot, дамп БД в R2; инструкция для персонала (1–2 стр.: как выставить телефон, как обработать заявку).
- [ ] **Запуск** по чеклисту 09 §3: домен → Node.js app, WP → `old.mano-phone.lt`.

## Этап 2: онлайн-продажа (~2 недели, когда понадобится)
- [ ] Договор Montonio, тестовые ключи на staging.
- [ ] Корзина и оформление, пакоматы, оплата, webhook, резерв 30 мин, возврат денег.
- [ ] Письма, PDF-счёт, экспорт для бухгалтерии; админка «Užsakymai».
- [ ] Юр. страницы покупки и возврата (14 дней).
**Готово, когда:** e2e-тест «витрина → оплата (тест) → PAID → письмо со счётом» зелёный, реальная покупка за 1 € с возвратом прошла на проде.

## Этап 3: рост (по мере надобности)
- RU и EN версии (перевод контента, hreflang, локализованные URL).
- Google Merchant Center, Facebook-каталог, Meta Pixel.
- Блог: 2 статьи в месяц по реальным запросам.
- Экспорт объявлений на skelbiu.lt.
- Аксессуары (обычные товары с остатком).
- Рассылка «nauji telefonai» (по согласию).

## Этап 4: управление сервисом (в конце, ~4–5 недель)
| Спринт | Что |
|---|---|
| 4.1 | Клиенты (`Customer`), онлайн-запись по слотам, календарь в админке, напоминания |
| 4.2 | Тикеты ремонта: создание из заявки или записи, приём на планшете (фото, подпись, акт PDF), канбан мастера |
| 4.3 | Согласование цены по ссылке, страница `/statusas/`, выдача, гарантийные талоны и обращения, напоминания «не забрали», просьба об отзыве |
| 4.4 | Скупка полностью: проверка, договор с шифрованием данных, выплата, автосоздание товара, trade-in в салоне |
| 4.5 | Отчёты (продажи, маржа, ремонт, скупка), CRM-карточка клиента, сканер QR и IMEI |

Перед этапом 4 стоит проверить, хватает ли ресурсов Hostinger Business. Скорее всего, хватит: нагрузка — это внутренние пользователи. При необходимости переезд на VPS делается без переписывания кода.

## Риски
| Риск | Что делаем |
|---|---|
| Падение позиций после миграции | keep-URL + 301 по таблице, ежедневный контроль Search Console, WP на `old.` 3 месяца |
| Лимиты Hostinger (память, сборка) | без тяжёлой серверной обработки; при падении сборки — сборка в GitHub Actions |
| Cron не сработал | бронь и резерв не зависят от cron (проверка по времени при каждом запросе); UptimeRobot следит за `/api/cron/health` |
| Владелец не успевает с ценами и текстами | начать в спринте 0; пустые цены показываются как «Kaina sutartinė» |
| Юр. вопросы (НДС, политика, возвраты) | проверка юристом или бухгалтером до спринта 4 |
