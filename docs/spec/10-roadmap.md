# 10. Дорожная карта

Оценка дана для 1 full-stack разработчика (+ дизайн). Спринт = 1 неделя.
**MVP (запуск вместо WP) = спринты 0–6, около 7 недель.** После запуска идут операционные функции и рост.

## Фаза 1: MVP (замена WordPress)

### Спринт 0. Подготовка
- [ ] Ответы владельца на открытые вопросы (README), юр. данные, договор с Montonio, SMS-провайдер.
- [ ] Новый репозиторий `mano-phone-web`, CI (lint, typecheck, test, build), staging-сервер, домен `staging.`.
- [ ] Дизайн: мудборд → UI-kit (цвета, типографика, кнопки, карточки) → макеты: главная, каталог, карточка, прайс модели, калькулятор, оформление (мобильные + десктоп).
- [ ] Выгрузка Search Console, фиксация текущих позиций.
**Готово, когда:** макеты утверждены, staging открывается, CI зелёный.

### Спринт 1. Фундамент
- [ ] Next.js + Tailwind + shadcn, next-intl (lt; ru и en под флагом), layout, шапка, футер, мобильная панель.
- [ ] Prisma + Postgres, миграции по `docs/spec/schema.prisma`, seed: 20 типов работ, 99 моделей, 1474 цены, 273 редиректа.
- [ ] Auth для персонала (2FA), каркас `/admin`, роли.
- [ ] Middleware: редиректы из БД, лог 404.
- [ ] `Setting`: компания, часы, контакты (один источник фактов).
**Готово, когда:** `/prietaisai/iphone-13-pro/` отдаёт 301 на `/remontas/iphone-13-pro/`, а там таблица цен из БД.

### Спринт 2. Ремонт (публичная часть) + админка прайса
- [ ] Страницы: прайс модели, бренд-посадочные, хабы, калькулятор, «Remontas visoje Lietuvoje», 11 городов (шаблон).
- [ ] Форма заявки на ремонт и диагностику, отправка по почте → тикет `NEW` + уведомление в Telegram.
- [ ] Админка: справочник моделей, матрица цен, массовые операции, CSV.
- [ ] Заполнить 151 пустую цену и 5 моделей, добавить iPhone 17 и Galaxy S25 (владелец).
**Готово, когда:** клиент находит модель, видит цену, оставляет заявку; владелец меняет цену и видит её на сайте ≤ 1 мин.

### Спринт 3. Каталог продажи (витрина + склад)
- [ ] Админка «Prekės»: создание экземпляра, фото (R2 + sharp), чеклист проверки, статусы, этикетка.
- [ ] Витрина `/telefonai/`: фильтры, сортировка, поиск, пагинация; карточка; «Parduota»-состояние; StockAlert.
- [ ] Блок «Naujausi telefonai» на главной.
**Готово, когда:** товар, опубликованный из админки, виден в каталоге с фильтрами, на мобильном LCP < 2 с.

### Спринт 4. Корзина, оплата, доставка
- [ ] Корзина, оформление, бронь в салоне.
- [ ] Montonio: оплата, webhook, refund; пакоматы.
- [ ] Резерв 30 мин и задачи pg-boss; письма и SMS (04 §6); PDF-счёт.
- [ ] Админка «Užsakymai»: статусы, выдача, возврат.
**Готово, когда:** e2e-тест Playwright проходит путь «каталог → оплата (тестовая) → PAID → письмо», а двойная продажа одного экземпляра невозможна (тест на гонку).

### Спринт 5. Скупка (базовая) + контент
- [ ] Калькулятор скупки, базовые цены и модификаторы в админке, заявка → `BuybackRequest` + Telegram.
- [ ] Блочный редактор страниц; перенести и переписать: главная, инфо (5), скупка (4), о нас, контакты.
- [ ] Юр. страницы: privatumas, slapukai, pirkimo taisyklės, grąžinimas, garantija; cookie-баннер + Consent Mode.
- [ ] Блог: 4 статьи с редиректами.
**Готово, когда:** у всех keep-URL есть новый контент, юр. страницы проверены владельцем или юристом.

### Спринт 6. SEO, качество, запуск
- [ ] JSON-LD (09 §5), sitemap (по языкам), robots, OG-картинки, hreflang.
- [ ] GA4 + GTM, события; Search Console; отзывы Google (`ReviewCache`).
- [ ] Lighthouse CI (≥ 90 mobile), доступность (axe), краулер по staging, проверка `redirects.csv` скриптом.
- [ ] Бэкапы, мониторинг, Sentry; инструкция для персонала (1–2 стр.).
- [ ] **Запуск** по чеклисту 09 §3.

## Фаза 3: Рост
- RU и EN версии (перевод контента, локализованные slug, hreflang).
- Google Merchant Center и Facebook Catalog (фиды), Meta CAPI.
- Этикетки доставки (Montonio Shipping), ремонт по почте «под ключ».
- Экспорт на skelbiu.lt, рассылки («nauji telefonai», «garantija baigiasi»).
- Аксессуары (обычные товары с остатком; потребуется `Product` + `stock`).
- Личный кабинет клиента (история, гарантии, повтор заказа).
- Smart-ID-подпись договора скупки, интеграция с бухгалтерией по API, проверка IMEI по API.

## Риски
| Риск | Что делаем |
|---|---|
| Падение позиций после миграции | keep-URL + 301 по таблице, контроль Search Console, старый сайт на `old.` |
| Владелец не успевает заполнить цены и тексты | начинаем со спринта 0, пустые цены показываем как «Kaina sutartinė» |
| Двойная продажа уникального экземпляра | транзакционный резерв, e2e-тест на гонку |
| Юр. требования (НДС маржа, скупка, хранение паспортов) | проверка юристом и бухгалтером до спринта 5 |
| Перегрузка персонала новыми процессами | фаза 2 по одному модулю в неделю + инструкция и обучение |
